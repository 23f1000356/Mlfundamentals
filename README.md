# ML Fundamentals

A single-page **ML Fundamentals — Complete Guide** reference. Open `Ml.html` in a browser (no build step required).

## Contents

The guide is organized into these sections:

1. **Statistics** — foundations for ML
2. **Regression**
3. **Classification**
4. **Perceptron**
5. **Support Vector Machine (SVM)**
6. **Ensemble methods**
7. **Summary**

## How to view

Clone this repository, then double-click `Ml.html` or open it from your browser via **File → Open**. An internet connection helps load the web fonts from Google Fonts.
