01
Foundation
Statistics
The mathematical language of data — describing, summarising, and drawing conclusions
Why it matters: Every ML model is built on statistical foundations. Without statistics you cannot understand your data, validate your model, or interpret predictions with appropriate confidence.

Descriptive Statistics

Descriptive statistics summarises what data looks like. Before training any model, you always start here.

Mean (μ) — the average
μ = Σxᵢ / n = (x₁+x₂+...+xₙ) / n
Sum all values, divide by count. Sensitive to outliers — one extreme value pulls the mean away from the centre of the data.
Median — the middle value
[10, 20, 60, 80, 95] Median = 60 (position 3)
Sort the data and take the middle. More robust than mean — a single extreme outlier doesn't distort it. Use when data has skew.
Variance (σ²) — the spread
σ² = (1/n) Σ(xᵢ − μ)²
Average of squared deviations from mean. Squaring ensures negatives and positives don't cancel. High variance = wide spread of scores.
Standard Deviation (σ)
σ = √σ² If mean = 53, σ = 30: 68% of images score 23–83 95% of images score −7–113
Square root of variance — restores original units. If your Laplacian scores have σ = 30, the range 23–83 contains most images.
Correlation (r) — linear relationship
r = Σ(xᵢ−μₓ)(yᵢ−μᵧ) / (n·σₓ·σᵧ) r = +1: perfect positive r = −1: perfect negative r = 0: no linear relationship
Correlation ≠ causation. Both ice cream sales and drowning deaths are high in summer — the third variable is hot weather, not the ice cream.

Normal Distribution — The Bell Curve

Most natural phenomena follow a normal distribution, characterised by its mean μ and standard deviation σ.

Normal distribution — the 68-95-99.7 rule
±1σ → 68.27%
Most data lives here. For Laplacian scores this is the typical range of borderline images.
±2σ → 95.45%
Almost all data. Values outside are statistically unusual — very blurry or very sharp.
±3σ → 99.73%
Extreme outliers. In a typical dataset fewer than 3 in 1000 images fall here.

Probability & Bayes' Theorem

Every ML model outputs probabilities. Conditional probability P(A|B) = probability of A given B has already happened.

P(A|B) = P(A ∩ B) / P(B) // Bayes' Theorem — the most important formula in statistics P(A|B) = P(B|A) · P(A) / P(B) // P(A) = prior: your belief BEFORE seeing evidence // P(B|A) = likelihood: how often you see B when A is true // P(A|B) = posterior: updated belief AFTER seeing evidence B
Bayes' theorem — worked example for blur detection
Class imbalance trap: Model says 90% confident = blurry. But if only 20% of images are truly blurry, the real probability is just 36%. This is why class imbalance in your training data critically matters.

Inferential Statistics

Draws conclusions beyond the data you have. Is this result real, or could it have happened by chance?

Hypothesis testing
H₀ (Null hypothesis): "My model is no better than random chance" — the boring, safe claim to disprove.

H₁ (Alternative): "My model IS better than random" — what you're hoping to prove.

p-value = probability of seeing your results if H₀ were true. Standard threshold: p < 0.05 = statistically significant → reject H₀.
Error types
Type I (α): Reject H₀ when true → False alarm → "My model is good" (it isn't) Type II (β): Fail to reject H₀ when false → Missed discovery → "My model is bad" (it isn't) Power = 1 − β = P(detect real effect)
02
Supervised Learning
Regression
Predicts a continuous number — price, score, temperature, sharpness rating
Key distinction: Regression outputs a number. Classification outputs a category. Predicting a sharpness score 0–100 = regression. Predicting blurry vs sharp = classification.

Linear Regression

Fits a straight line through data points to predict y from x. The model learns the slope m and intercept b from data. Example: predict polish loss (mg) from tumbling time (minutes) in a linear range — each extra minute removes roughly a constant amount until saturation (then you would extend with polynomial or a different model).

Simple: y = mx + b Multiple: y = w₁x₁ + w₂x₂ + ... + wₙxₙ + b // y = predicted value (sharpness rating) // m = slope (how much y changes per unit of x) // b = intercept (y when x = 0) // wᵢ = learned weights for each feature
Linear regression — best-fit line minimising squared residuals (red)

Ordinary Least Squares — Finding the Best Line

MSE = (1/n) Σ (yᵢ − ŷᵢ)² // yᵢ = actual value ŷᵢ = predicted value // Squaring: off-by-10 penalised 4× more than off-by-5 Closed-form exact solution: w = (XᵀX)⁻¹ Xᵀy

Gradient Descent — Iterative Optimisation

For large datasets, instead of solving exactly, descend the error surface step by step — like rolling a ball downhill to find the lowest point.

w := w − α · ∂MSE/∂w b := b − α · ∂MSE/∂b // α = learning rate: size of each step // ∂MSE/∂w = gradient: direction downhill // := means "update with" Repeat until weights converge
Batch GD
Uses ALL training data per step. Accurate but slow for large datasets.
SGD
One random sample per step. Very fast but noisy — bounces around the minimum.
Mini-batch (Adam)
Batches of 32–512. Best of both. Used in EfficientNet training.

Evaluation Metrics

R² — coefficient of determination
R² = 1 − Σ(yᵢ−ŷᵢ)² / Σ(yᵢ−μᵧ)² R² = 1.0 → perfect fit R² = 0.0 → no better than predicting mean R² < 0.0 → worse than predicting mean
R²=0.85 means "85% of the variance in sharpness is explained by the Laplacian score."
MAE & RMSE
MAE = (1/n) Σ |yᵢ − ŷᵢ| RMSE = √((1/n) Σ (yᵢ−ŷᵢ)²)
MAE — average absolute error in original units. Easy to interpret. RMSE — penalises large errors more. Choose RMSE when large mistakes are especially costly.

Regression algorithms in detail

Every regression method chooses a function family for f(x), a loss L(y, ŷ), and usually a regulariser to control complexity. The right choice depends on linearity, outliers, dimensionality, and whether you need calibrated probabilities or interpretable splits. Neural regression uses the same MSE or Huber head as classical models, but h(x) is a deep network — so non-linearity is learned from raw inputs (pixels, waveforms) rather than hand-built features.

Regularised linear & generalised linear regression

Ridge (L2) shrinks all coefficients smoothly toward zero but rarely sets them exactly to zero — good when many weakly relevant features exist. Lasso (L1) encourages sparsity and performs implicit feature selection. Elastic Net blends both so correlated groups of features (e.g. many Laplacian variants) can survive together while still shrinking noise.

Elastic Net loss (single response): J(w) = (1/n) Σ (yᵢ − xᵢᵀw)² + λ₁‖w‖₁ + λ₂‖w‖₂² // λ₁ dominates → Lasso-like sparsity // λ₂ dominates → Ridge-like stability on correlated columns // Logistic “regression” is GLM: linear score + link → probability g(E[y|x]) = wᵀx + b with g = logit for binary counts
When to prefer which penalty
Ridge: p ≫ n (many features, few samples), multicollinearity, all features potentially useful.

Lasso: you believe only a subset of features matter; need a sparse model for deployment speed.

Elastic Net: default compromise in many tabular pipelines when features are correlated (common in engineered scores).
Robust & quantile variants
Huber loss reduces the influence of outliers compared to pure squared error — useful when sharpness labels are noisy.

Quantile regression predicts a chosen percentile of y (e.g. 10th and 90th percentile blur score) instead of the mean — helpful for risk-aware thresholds.

Geometry of penalties (intuition): With a fixed loss budget, Ridge pulls weights toward the origin along a spherical (L2) surface — many small weights. Lasso prefers solutions on the coordinate axes — some weights become exactly zero, dropping features from the model entirely.

L2 (Ridge) vs L1 (Lasso) — constraint regions in 2D weight space (w₁, w₂)

Support vector regression (SVR)

SVR finds a function that stays within an ε-tube around as many training points as possible while keeping the slope “flat” in feature space (small ‖w‖). Points outside the tube become support vectors and pay a linear hinge penalty.

Primal idea: minimise ½‖w‖² + C Σ ξᵢ + C Σ ξᵢ* subject to |yᵢ − (wᵀφ(xᵢ)+b)| ≤ ε + ξᵢ // ε = tube half-width — larger ε → fewer support vectors, smoother fit // C = trade-off between flatness and tolerance of errors outside tube // φ(x) = implicit feature map; kernel K(x,x′)=φ(x)ᵀφ(x′) for non-linear SVR
SVR — ε-insensitive tube around the regressor f(x); points outside pay slack
Practical note: SVR shines on medium-sized tabular problems with non-linear structure. On very large datasets, kernel methods become expensive (training is super-linear in n); tree ensembles or neural nets are often easier to scale.

Regression trees, random forests & gradient boosting

CART regression trees split each node to minimise weighted MSE in the children. Leaves predict the mean of training y in that region — piecewise-constant surfaces with axis-aligned boundaries.

Regression tree — recursive axis-aligned splits partition feature space; each leaf predicts ȳ (mean y)

Each internal node stores a split rule (feature index + threshold). Leaves store a constant prediction. Deeper trees fit training data more tightly; shallower trees generalise better but underfit if depth is too small.

Split impurity (MSE) for candidate split S into L and R: Δ = Σᵢ∈L (yᵢ − μL)² + Σᵢ∈R (yᵢ − μR)² // choose split minimising total child MSE Random Forest regressor: ŷ(x) = (1/B) Σᵦ fᵦ(x) // each fᵦ is a deep tree on a bootstrap sample + random feature subset Gradient boosting (regression): Fₘ(x) = Fₘ₋₁(x) + η · hₘ(x) // hₘ fits pseudo-residuals rᵢ = −∂L/∂ŷ at ŷ = Fₘ₋₁(xᵢ); typical L = squared error
Single tree
Very interpretable; high variance. Control depth, min samples per leaf, or pruning to avoid memorising noise.
Random Forest
Bagging + decorrelated trees. Lower variance; strong default for heterogeneous tabular features (Laplacian, FFT, metadata).
Boosting (GBDT)
Sequential bias reduction. Often best accuracy on structured data; tune learning rate, depth, and early stopping to avoid overfit.

Random Forest training recipe: draw B bootstrap samples of n rows; for each, grow a tree where each split considers only a random subset of mtry features (often √p for classification, p/3 for regression). OOB error evaluates each tree on the ~37% of rows left out of its bootstrap — a free validation curve as B increases.

Supervised Learning
Classification
Predicts which category something belongs to — the core of your blur detector
Your entire blur/sharp pipeline is binary classification. Two classes: blurry (0) and sharp (1). EfficientNetB0 is a classifier — its final sigmoid layer outputs P(sharp | image).

Decision Boundary

Binary classification
Two classes. Blurry vs Sharp. Spam vs Not-spam. One decision boundary separating them.
Multi-class
3+ classes. Ring, Bangle, Necklace. One winner. Softmax output layer — all probs sum to 1.
Multi-label
Multiple tags simultaneously. Blurry AND dark AND damaged. Several winners possible.

In 2D feature space, a linear classifier (logistic regression, linear SVM) draws a single line (or plane in higher D). A tree draws nested rectangles. A k-NN boundary is locally stitched from Voronoi-like regions. Neural nets can approximate highly curved boundaries but need enough data to avoid spurious folds.

Binary decision regions — linear boundary vs axis-aligned tree partition (schematic)

Threshold choice: Moving the decision threshold (e.g. from 0.5 on p(sharp)) trades precision for recall — essential when false negatives cost more than false positives.

Pick the problem type first (how many labels? mutually exclusive?). Then choose an algorithm family that matches data size, interpretability needs, and whether you need calibrated probabilities.

Key classification algorithms

These four are the classical baselines: cheap to train, easy to explain, and strong sanity checks before you invest in deep models or heavy ensembles.

Logistic Regression
p = σ(w·x + b) = 1/(1+e^(−(w·x+b))) p ≥ 0.5 → class 1 (sharp) p < 0.5 → class 0 (blurry)
Linear boundary in feature space. Optimises log-loss (cross-entropy), which is well-calibrated if the model is not misspecified. Fast, interpretable coefficients (each feature’s log-odds contribution). Always compare your CNN’s AUC to a regularised logistic on the same tabular scores.

Example: Train on rows [Laplacian=42, FFT=0.31, size_kb=890] → label sharp; after fitting, a new image with [55, 0.28, 920] might get p(sharp)=0.82.
Decision Tree
if Laplacian_score < 50: → blurry elif FFT_score < 30: → blurry else: → sharp
Greedy axis-aligned splits maximise information gain (entropy/Gini reduction). Highly interpretable; prone to high variance — tiny data changes can flip splits. Use max_depth, min_samples_leaf, cost-complexity pruning, or go straight to ensembles.

Example: Root split “Laplacian < 48?” sends dark soft images left; left child “JPEG Q < 70?” further splits compression artefacts from true motion blur.
K-Nearest Neighbours (KNN)
class = majority_vote(K nearest) distance = √(Σ(xᵢ−zᵢ)²)
Instance-based: decision boundary adapts locally. No training but prediction cost grows with n. Scale features first (KNN is distance-sensitive). Choose odd K for binary voting ties; weight votes by inverse distance for smoother boundaries.

Example: With K=5 in 2D [Laplacian, FFT] space, a query image inherits the majority label among its 5 nearest training neighbours — useful for a quick sanity check on a few hundred labelled tiles.
Naive Bayes
P(class|x) ∝ P(class)·ΠP(xᵢ|class)
Generative shortcut: assumes features are conditionally independent given the class. Gaussian NB for continuous scores, Multinomial/Bernoulli for counts. Extremely fast on high-dimensional sparse data (e.g. text). Calibration can be poor — pair with Platt scaling or isotonic regression if you need trustworthy probabilities.

Example: Gaussian NB with one variance per class per feature: P(sharp | Laplacian=60) ∝ P(sharp)·P(Lap=60|sharp) — if sharp images rarely show Laplacian below 30, very low scores push toward blurry even before seeing other features.

Classification algorithms in depth

Beyond baselines, most production classifiers are margin-based (SVM), tree ensembles (random forest, boosting), or neural networks. They differ in how they carve up feature space, what loss they optimise, and how they behave under class imbalance.

Support vector machines (linear & kernel)

A hard-margin linear SVM finds the hyperplane that separates classes with the largest gap (margin) between the closest points (support vectors). Soft-margin SVM allows slack ξᵢ for overlap; C trades margin width vs violations. Non-linear boundaries use the kernel trick — same optimisation in a richer feature space without explicitly computing φ(x).

Primal (soft-margin): minimise ½‖w‖² + C Σ ξᵢ subject to yᵢ(wᵀxᵢ + b) ≥ 1 − ξᵢ , ξᵢ ≥ 0 // yᵢ ∈ {−1,+1} (encode blurry/sharp as −1/+1) // Large C → fit training points tightly (lower bias, higher variance) // Small C → wider margin, more tolerance of misclassification on train Dual (kernelised): maximise Σ αᵢ − ½ Σᵢⱼ αᵢ αⱼ yᵢ yⱼ K(xᵢ,xⱼ) // Common K: linear, RBF exp(−γ‖x−x′‖²), polynomial (xᵀx′+c)^d
Linear SVM — maximum margin hyperplane; support vectors lie on the margin edges
When SVM still wins: Small-to-medium tabular datasets, especially when classes are separable with a smooth boundary in a lifted space. For images, raw-pixel SVMs are obsolete — but SVM on engineered features (Laplacian, FFT, colour stats) can still be a strong cheap baseline next to logistic regression.

Tree ensembles — random forest & gradient boosting

Random Forest trains many deep trees on bootstrap samples with random feature subsets at each split; the final vote or average probability reduces variance and resists overfitting better than a single tree. Gradient boosting (XGBoost, LightGBM, CatBoost) fits trees sequentially: each new tree predicts the negative gradient of the loss w.r.t. the current model output (pseudo-residuals). Boosting aggressively reduces bias but needs careful tuning (learning rate η, max depth, subsample, early stopping).

Random Forest vote: ŷ = argmax_c Σᵦ 𝟙[fᵦ(x) = c] // classification majority over B trees Gradient boosting step (multiclass uses K vectors Fᵏ): Fₘ(x) = Fₘ₋₁(x) + η · hₘ(x) with hₘ fitted to −∂L/∂Fₘ₋₁ // Binary log-loss → pseudo-residuals ≈ (yᵢ − pᵢ)
Random Forest — strengths
Robust default; handles non-linearity and interactions; out-of-bag error estimate; little preprocessing. Feature importance (impurity decrease or permutation) helps debug which scores drive blur vs sharp.
Boosting — strengths
Often highest accuracy on structured/tabular data; built-in handling of missing values in some libraries; monotone constraints available for business rules. Watch for overfitting without early stopping and strong regularisation.

Gradient boosting intuition: the first weak learner F₀ might be the log-odds of the positive class rate. Each tree hₘ corrects the errors of the sum so far; with squared error regression those targets are literal residuals, with log-loss they are probability gaps. Shrinkage η < 1 forces many small corrections instead of a few large jumps — almost always improves generalisation.

Neural classifiers & softmax

Deep networks stack learned feature extractors with a linear classifier head. Binary problems use a single sigmoid output; multi-class uses softmax over K logits so probabilities sum to 1. Training minimises cross-entropy, which is the natural companion to softmax (maximum likelihood under a multinomial model).

Softmax: P(y=k|x) = e^(zₖ) / Σⱼ e^(zⱼ) where z = W h(x) + b Cross-entropy: L = − Σₖ yₖ log ŷₖ // one-hot y for multi-class // Binary blur: single logit + sigmoid = 2-class softmax with shared parametrisation
Softmax turns logits z into a probability vector — larger zₖ → larger mass (exponential amplifies gaps)

CNNs (e.g. EfficientNetB0) learn h(x) from pixels; transfer learning freezes early layers and fine-tunes the head when data is limited. Label smoothing replaces hard one-hot targets with a mixture with the uniform distribution, reducing overconfidence. Focal loss multiplies cross-entropy by (1 − pₜ)^γ so well-classified examples contribute less gradient — valuable when negatives vastly outnumber positives.

Accuracy = (TP+TN) / (TP+TN+FP+FN) Precision = TP / (TP+FP) ← of all predicted sharp, how many are? Recall = TP / (TP+FN) ← of all actual sharp, how many found? F1 Score = 2·(Precision·Recall)/(Precision+Recall) harmonic mean — penalises extreme imbalance AUC-ROC = area under TPR vs FPR curve 1.0 = perfect, 0.5 = random guessing

ROC vs PR: ROC-AUC integrates true-positive rate vs false-positive rate as you sweep the threshold. With heavy class imbalance, ROC can look optimistic because FPR is dominated by the huge negative class. Precision–Recall AUC focuses on the minority class and often aligns better with business cost when positives are rare.

ROC curve — every threshold is one point; AUC = area above the diagonal

Calibration: A model can have high AUC yet give poorly calibrated probabilities (predicted 0.9 vs actual 60% positive rate among those bins). Tools: reliability diagrams, Platt scaling, isotonic regression on a held-out set.

For your blur project: Recall matters more than Precision. A False Negative (discarding a sharp image forever) is worse than a False Positive (a blurry image sits in the sharp folder). Consider lowering the threshold from 0.5 to 0.4 to maximise recall.
04
Neural Networks
Perceptron
The original artificial neuron — building block of every neural network
The big picture: One perceptron = one artificial neuron. Stack thousands in layers = neural network. Stack millions = EfficientNetB0. Understand the perceptron and you understand every deep learning model.

A Single Perceptron — All Parts

Single perceptron — inputs · weights · weighted sum · activation · output
z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b ← weighted sum (pre-activation) output = f(z) ← apply activation function

Activation Functions

Without activations, stacking 100 linear layers is still just one linear transformation. Non-linearity is what allows networks to learn complex real-world patterns.

Step (original perceptron)
f(z) = 1 if z ≥ 0, else 0
Binary output. Not differentiable — cannot use gradient descent. Historically important. Not used today.
Sigmoid — output layer for binary
σ(z) = 1 / (1 + e^(−z)) output: (0,1)
Smooth, differentiable, outputs probability. Problem: vanishing gradients for large/small z. Best used in output layers only.
ReLU — default for hidden layers
f(z) = max(0, z) output: [0, ∞)
Fast to compute. Gradient = 1 for z > 0 — no vanishing gradient. EfficientNet uses Swish: z·σ(z), a smooth variant of ReLU.
Softmax — multi-class output
softmax(zᵢ) = e^zᵢ / Σⱼ e^zʲ All outputs sum to 1
Use when you have 3+ classes (Ring, Bangle, Necklace, Pendant). Each output = probability of that class. The highest wins.

Backpropagation — How the Network Learns

1
Forward pass: Input flows through all layers. Each neuron computes z = w·x + b then f(z). Final layer produces prediction ŷ.
2
Compute loss: Compare ŷ to true label y. For binary classification: L = −[y·log(ŷ) + (1−y)·log(1−ŷ)]
3
Backward pass: Compute ∂L/∂w for every weight using the chain rule. Gradients flow backward from output to input layer by layer.
4
Weight update: w := w − α · ∂L/∂w. Each weight moves a small step reducing the loss. Repeat for thousands of batches.
// Chain rule — the mathematical heart of backpropagation ∂L/∂w_l = (∂L/∂a_L) · (∂a_L/∂a_{L-1}) · ... · (∂a_{l+1}/∂w_l) // Each layer multiplies its local gradient by the upstream gradient // Vanishing gradients: multiply many values < 1 → gradient ≈ 0 → no learning // ReLU solves this: gradient is exactly 1 (not a fraction) for z > 0
05
Supervised Learning
Support Vector Machine
Finds the widest possible gap between classes — the maximum margin classifier
Core insight: SVM finds the line where the gap to the nearest points on both sides is maximised. Those nearest points are the support vectors. Remove any other point — the boundary doesn't move. This is why SVMs generalise well with small datasets like your 30-image test set.

The Core Idea — Maximum Margin

SVM — maximum margin boundary between blurry and sharp images

The Mathematics

// Decision boundary (hyperplane) w · x + b = 0 // Classification rule w · x + b > 0 → class +1 (sharp) w · x + b < 0 → class −1 (blurry) // Margin boundaries — support vectors sit on these w · x + b = +1 ← sharp support vectors here w · x + b = −1 ← blurry support vectors here Margin width = 2 / ‖w‖ // Maximise margin = minimise ‖w‖ Minimise: ½‖w‖² Subject to: yᵢ(w·xᵢ + b) ≥ 1 for all i // Soft margin (allows some violations — for real noisy data) Minimise: ½‖w‖² + C·Σξᵢ Subject to: yᵢ(w·xᵢ + b) ≥ 1 − ξᵢ, ξᵢ ≥ 0
C — high value
Small margin, few misclassifications allowed. Risk of overfitting. Use when data is clean.
C — low value
Large margin, more misclassifications tolerated. Better generalisation. Use when data is noisy.

The Kernel Trick — Non-Linear Boundaries

Real data is rarely linearly separable. The kernel trick maps data into a higher-dimensional space where a linear boundary works — without ever computing the transformation explicitly.

Linear: K(xᵢ,xⱼ) = xᵢ · xⱼ Polynomial: K(xᵢ,xⱼ) = (xᵢ · xⱼ + c)^d RBF: K(xᵢ,xⱼ) = exp(−γ‖xᵢ−xⱼ‖²) ← most powerful general-purpose // γ in RBF: small γ = broad influence, large γ = tight (risk of overfitting) // Tune C and γ with cross-validation: try C ∈ {0.1,1,10,100}, γ ∈ {0.001,0.01,0.1,1}
06
Advanced ML
Ensemble Methods
Combine many weak models into one strong model — the wisdom of the crowd applied to ML
The core insight: No single model is perfect. Every model makes different errors. When you combine many models, errors partially cancel — the result is almost always better than any individual model. This is why ensemble methods win most ML competitions.

Bias-Variance Trade-off

Total Error = Bias² + Variance + Irreducible Noise // Bias = how wrong on average (underfitting) // Variance = how much predictions change with different training data (overfitting) // Irreducible noise = randomness in data itself — cannot be removed
High bias (underfitting)
Model too simple. Wrong on training AND test data. A single decision stump misses complex blur patterns.
High variance (overfitting)
Model too complex. Right on training, wrong on test. A deep tree memorises every training image.
The goal
Minimise both. Bagging reduces variance. Boosting reduces bias. Stacking reduces both at once.
Bagging (parallel) vs Boosting (sequential) — how each combines models

Bagging — Bootstrap Aggregating

For each model t = 1 to T: 1. Draw bootstrap sample Bₜ (random, with replacement) 2. Train model hₜ on Bₜ independently Final prediction: H(x) = majority_vote{ h₁(x),...,hₜ(x) } ← classification H(x) = (1/T) Σ hₜ(x) ← regression

Random Forest — Bagging + Random Features

For each tree: Bootstrap sample from training data At each split: consider only √n random features (not all n features) Grow tree to maximum depth — no pruning H(x) = majority vote of all T trees // Random feature selection decorrelates trees → errors more independent → better combining

Boosting — Sequential Error Correction

AdaBoost
Start: equal weights on all samples For each round t: 1. Train weak hₜ (e.g. decision stump) 2. εₜ = Σ(weights of misclassified) 3. αₜ = 0.5·ln((1−εₜ)/εₜ) ← model weight 4. Increase weight on misclassified 5. Decrease weight on correct H(x) = sign(Σ αₜ·hₜ(x))
XGBoost — Gradient Boosting
F₀(x) = initial prediction (mean of y) For t = 1 to T: rᵢ = −∂L/∂F(xᵢ) ← residuals Train tree hₜ on residuals rᵢ Fₜ(x) = Fₜ₋₁(x) + α·hₜ(x) // Adds L1/L2 regularisation // Handles missing data automatically // Wins most tabular data competitions

Stacking — The Meta-Model

// Level 1 — base models (trained on original features) Model A: SVM on [Laplacian score, FFT score] Model B: Random Forest on [Laplacian, FFT, file size] Model C: EfficientNetB0 → p_sharp // Level 2 — meta-model learns to combine base outputs Meta features: [pred_A, pred_B, pred_C] Meta model: Logistic Regression Final = Meta_model(pred_A, pred_B, pred_C) // Meta-model learns: "trust EfficientNet for Rings, Laplacian for Bangles"
